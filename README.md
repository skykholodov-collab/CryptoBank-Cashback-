# Кешбэк-кейсы

Нативный Android-прототип кешбэка для Казахстана. Валюта интерфейса — тенге (₸).

Рабочее название приложения — **«Кешбэк-кейсы»**. Имя репозитория не является названием продукта и не означает связь с банком, криптосервисом или реальной компанией.

Кейс здесь — только визуальная обложка фиксированной подборки предложений. Открытие не является розыгрышем, ничего не стоит и не выбирает случайный приз.

## Что показывает демо

Три экрана:

1. Каталог из трёх подборок: «Город», «Дом и техника», «Сервис».
2. Карточка предложения: образец ставки, условия, пример суммы покупки, расчёт и подтверждение демо-активации.
3. Баланс и история. Суммы разделены на «ожидает» и «подтверждено». Кнопка вывода видима и выключена.

Все продавцы, ставки, покупки и суммы — вымышленные образцы. Максимальная ставка в каталоге — 10% и только как образец с квалифицирующей покупки. На устройстве нет сети, платёжного API, приёма денег и выплаты.

Состояние хранится в локальном JSON. «Сбросить демо» возвращает начальный образец: 225 ₸ подтверждено (кофейня) и 840 ₸ ожидает (техника).

## Чего в прототипе нет

- Приёма оплаты, платёжных реквизитов и вывода денег.
- Договоров с реальными продавцами и ссылок на их сайты.
- Обещания дохода, таймера срочности и сценария «деньги за два часа».
- Пополнения баланса, инвестиционного продукта и выплат за счёт новых участников.
- Платного открытия кейса и случайного приза.
- Юридического заключения или разрешения для Казахстана. Этот репозиторий их не создаёт и не подтверждает.

## Требования

- JDK 17 или новее (сборка проверена на JDK 21).
- Android SDK: `platform-tools`, `platforms;android-35`, `build-tools;35.0.0`.
- Для эмулятора дополнительно: `emulator` и образ `system-images;android-34;aosp_atd;x86_64`.

Переменная `ANDROID_HOME` должна указывать на SDK. Файл `local.properties` в git не входит:

```bash
echo "sdk.dir=$ANDROID_HOME" > local.properties
```

## Сборка debug APK

```bash
./gradlew :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

Это debug-сборка с отладочной подписью. Её нельзя публиковать в магазине и нельзя считать готовой к приёму денег.

## Тесты

```bash
./gradlew :core:test
```

Модуль `:core` проверяет потолок ставки 10%, округление до целых тенге, статусы «ожидает» и «подтверждено», запрет второй активной записи, локальное подтверждение без изменения правил вывода, сохранение JSON, сброс и отсутствие запрещённых формулировок в исходниках приложения.

На подключённом эмуляторе или устройстве:

```bash
./gradlew :app:connectedDebugAndroidTest
```

Инструментальный тест открывает подборку «Сервис», активирует образец покупки 27 500 ₸ у «Тулпар Тревел» (10% → 2 750 ₸), проверяет, что вывод остаётся выключенным, локально переводит запись в «подтверждено» и сбрасывает демо к 840 ₸ / 225 ₸.

## Запуск

Откройте проект в Android Studio и запустите конфигурацию `app`, либо установите APK:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n kz.cashbackcases.demo/.MainActivity
```

Интерфейс русский. Даты в истории показываются по часовому поясу Алматы.

## Что понадобится для настоящего запуска

Денежные операции сюда сознательно не встроены. Чтобы они вообще стали возможны, нужны отдельные решения. Их нет в этом прототипе, и README не утверждает, что они уже приняты или одобрены:

1. Юридическое лицо и проверка модели по праву Казахстана: оферта, персональные данные, реклама условий. Это не юридическое заключение.
2. Договоры с продавцами. Кешбэк в рабочей модели финансируется комиссией партнёра после квалифицирующей покупки, а не взносами участников.
3. Сервер, который подтверждает покупку сам: аутентифицированный postback или другая сверка. Локальная кнопка «подтверждено» для этого не подходит.
4. Журнал начислений с идемпотентностью и аудитом. Телефон не должен быть источником истины.
5. Провайдер выплат по отдельному договору. Провайдер не выбран. Его идентификация и правила подключаются по документам провайдера и применимому праву, а не по этому файлу.

Пока этого нет, приложение должно оставаться демонстрацией с явным демо-баннером и выключенным выводом.
